# 多功能生活助手（astrbot_all_char）

`astrbot_all_char` 是一个 AstrBot 整合插件。它把 char 系列里常用的查询、提醒、记忆、搜索、娱乐和生活工具合并到一个仓库里，统一配置、统一命令、统一维护。

当前代码实际接入的能力包括：

- 火车票查询
- 全球天气查询
- 简易提醒
- 主动消息 / 轻量主动聊天
- 会话总账 / 短期会话记忆 / 聊天上下文增强
- 任务线程 / 事后反思 / 睡眠整理
- 永久记忆 / 被动记忆 / 记忆面板
- 群聊黑话学习
- 股票 / 基金分析
- LoL 国服战绩与群订阅
- 记账
- 今日运势
- 趣味玩法（今日人设 / 吃什么 / 抽签）
- OCR 图片识别
- 动漫截图识别
- 百度千帆智能搜索 / 网页搜索
- 点歌
- 邮件发送 / 邮件订阅

## 1. 项目特点

- 一个插件整合多类高频功能，不再拆成一堆零散插件维护。
- 同时支持命令调用和 LLM Tool 调用，适合接入 Agent / Skill。
- 普通聊天进入模型前会自动注入人物记忆、被动偏好、相关人物回忆、任务线程和黑话解释。
- bot 会在回复后做轻量“事后反思”，并通过“睡眠整理”合并线程、归档完成事项，让长期对话更连续。
- 配置集中在 [`_conf_schema.json`](_conf_schema.json)，说明比散落在代码里更完整。
- 多数状态已统一走 SQLite 或统一状态存储，老 JSON 数据会尽量自动迁移。

## 3. 安装

1. 将本仓库放入 AstrBot 插件目录并启用插件。
2. 安装运行时缺少的依赖。
3. 在 AstrBot 插件配置页填写需要的配置项。
4. 重启 AstrBot。

常见额外依赖如下，若你的运行环境已自带可跳过：

```bash
pip install aiohttp aiofiles pillow akshare pandas apscheduler
```

说明：

- `apscheduler` 强烈建议安装。
- 未安装 `apscheduler` 时，`/提醒` 持久化调度、邮件订阅、股票定时提醒会受影响。
- 主动聊天和 LoL 订阅有回退循环逻辑，但仍建议安装 `apscheduler`。

## 4. 配置重点

完整配置说明请直接看 [`_conf_schema.json`](_conf_schema.json)。

常用配置组如下：

| 配置组 | 关键项 | 用途 |
| --- | --- | --- |
| `memory` | `memory_admin_qq_ids` | 记忆、记忆面板、管理员能力的权限控制 |
| `memory` | `memory_panel_*` | 记忆面板开关、监听地址、端口、外网地址 |
| `slang` | `slang_enabled` 等 | 黑话学习与注入控制 |
| `weather` | `weather_*` | 天气数据源与返回格式 |
| `train` | `train_*` | 12306 基础地址与返回格式 |
| `sy` | `sy_*` | `/提醒` 与旧 `/rmd` 兼容配置 |
| `proactive` | `proactive_*` | 轻量主动聊天、目标 QQ / 群号、时段规则 |
| `conversation` | `conversation_*` | 会话总账、短期会话记忆、聊天前上下文增强 |
| `cognition` | `cognition_*` | 任务线程、事后反思、睡眠整理与认知提示预算 |
| `stock` | `stock_ai_provider_id` | 股票 AI 分析模型提供商 |
| `fund` | `fund_ai_provider_id` | 基金 AI 分析模型提供商 |
| `lol` | `lol_tencent_cookie` | LoL 国服战绩查询所需 WeGame Cookie |
| `ocr` | `ocr_provider_id` | OCR 使用的视觉模型提供商 |
| `qianfan_search` | `qianfan_search_ak` | 百度千帆搜索 API Key |
| `music` | `nodejs_base_url` 等 | 点歌接口和发送模式 |
| `email` | `email_sender`、`email_auth_code` | QQ 邮箱发件配置 |
| `jrys` | `jrys_*` | 今日运势素材与行为控制 |

建议先最少配置这些：

- `memory.memory_admin_qq_ids`
- `qianfan_search.qianfan_search_ak`
- `email.email_sender`
- `email.email_auth_code`
- `ocr.ocr_provider_id`
- `stock.stock_ai_provider_id`
- `fund.fund_ai_provider_id`
- `lol.lol_tencent_cookie`

## 5. 命令速查

### 基础查询

```text
/火车票 厦门 上海
/火车票 4月20号 厦门 上海
/天气 北京
/天气 上海 5
/天气 Paris, FR 明天
```

说明：

- `/火车票` 支持 `YYYY-MM-DD`、`YYYY年M月D日`、`M月D日/号`、`今天/明天/后天/大后天`。
- `/天气` 默认使用 Open-Meteo，支持全球城市；重名城市建议写成 `城市, 国家代码`。

### 提醒与主动消息

```text
/提醒 3分钟后 喝水
/提醒 明天下午3点 开会
/提醒 列表

/主动消息 绑定 工作群
/主动消息 列表
/主动消息 发送 群 工作群 今天 18:00 开会
/主动消息 删除 群 工作群
```

说明：

- 旧 `/rmd`、`/rmdg` 目前只保留简化入口，推荐直接用 `/提醒`。
- `/主动消息` 仅允许管理员使用。
- 新项目更推荐直接配置 `proactive_private_qq_ids`、`proactive_group_ids` 和 `proactive_time_slots` 做自动主动聊天。

### 记忆、认知增强、黑话、记忆面板

```text
/认人 123456789 阿周 初中同学
/记忆 设置 123456789 阿周 全局 初中同学
/记忆 查看 123456789
/记忆 列表
/我是谁

/记忆面板
/记忆面板 状态
/记忆面板 关闭
/会话上下文
/任务线程
/任务线程 全部
/任务线程 查看 12
/任务线程 完成 12
/任务线程 搁置 12
/任务线程 整理

/黑话 列表
/黑话 解释 yyds
/黑话 学习 yyds = 永远的神
/黑话 删除 yyds
```

说明：

- 永久记忆命令、记忆面板启动/关闭仅管理员可用；面板网页默认不需要 token，能连到端口的人都能查看和编辑。
- 普通聊天进入模型前，会自动按当前 QQ 注入长期记忆。
- 普通聊天还会额外注入“会话态势”，让 bot 更清楚最近这段时间在聊什么、你现在在忙什么、它上轮答应过什么。
- 普通聊天也会自动提炼“任务线程”，记录你最近在推进什么、下一步是什么、是否已经完成。
- bot 回复后会记录轻量“事后反思”，并在后台做“睡眠整理”：标记久未活跃事项、合并相近线程、把高置信已完成事项归档进事件记忆。
- `/任务线程` 可查看当前任务线程；`/任务线程 整理` 会立刻执行一次睡眠整理。
- `/会话上下文` 可直接查看当前会话最近消息、短期记忆和最近话题，方便排查聊天增强效果。
- 黑话默认按当前群聊 / 私聊 / 会话隔离存储。

### 趣味玩法

```text
/今日人设
/今日人设 打工版
/吃什么
/今天吃什么 晚饭 减脂
/抽签
/抽签 这周要不要推进副业
```

说明：

- `/今日人设` 会按当天日期、当前用户和可选关键词生成一个“今日限定人设”。
- `/吃什么` 会按当前时段和关键词推荐 3 个候选，适合处理“今天到底吃啥”。
- `/抽签` 支持不带问题随手抽，也支持带问题做轻量解签；同一天问同一个问题结果保持一致。

说明：

- `/智能搜索` 每日本地上限 100 次，`/搜索` 每日本地上限 1000 次。
- 点歌支持“先搜后选”，回复纯数字可以选择候选歌曲。
- `/今日人设`、`/吃什么`、`/抽签` 都是零配置命令，不依赖额外 API。

已做过或仍保留自动迁移逻辑的模块包括：

- 永久记忆：旧 `user_memory.json` 会迁移到 SQLite。

- 股票自选 / 提醒：旧 JSON 状态会迁移到当前存储。
- 其他模块的 JSON 状态会尽量通过统一状态表接管。

## 8. 记忆面板说明

记忆面板是这个仓库里比较重要的一块能力。

- 入口命令：`/记忆面板`
- 管理命令：`/记忆面板 状态`、`/记忆面板 关闭`
- 默认监听：`0.0.0.0:7835`
- 返回方式：命令会返回普通访问链接，默认不需要 `token`
- 可选鉴权：如需恢复临时 token 访问，可开启 `memory_panel_require_token`
- 可配置公网地址：`memory_panel_public_base_url`
- 端口占用时：
  - 未配置公网地址时，会自动顺延到下一个空闲端口
  - 已配置固定公网地址时，会提示你同步调整端口和地址

面板里可以直接查看和编辑：

- 人物基础记忆与别名
- 偏好、关系、事件回忆
- 跨模块习惯记忆
- 记账记录
- 简易提醒

如果面板监听 `0.0.0.0` 且未开启 token，请只在可信网络使用，或通过防火墙 / 反向代理限制访问来源。

## 9. 平台与使用注意

- `metadata.yaml` 声明支持 `telegram`、`discord`、`wecom`、`qq_official`、`dingtalk`、`lark`、`line`、`satori`。
- 但部分能力明显偏 QQ 场景：
  - 永久记忆管理员按 QQ 号控制
  - LoL 国服查询和群订阅
  - 主动消息按 QQ 号 / 群号直发当前只支持 `aiocqhttp`
  - 点歌的某些发送模式在 QQ 平台体验更完整
- 股票 / 基金智能分析、OCR、部分邮件生成依赖 AstrBot 中已配置的大模型提供商。
- `/发邮件`、`发邮件到 ...`、含“邮件 + 邮箱地址”的自然语言消息都会尝试进入真实发信流程。
